# 计算机学院学生会举办第四期“芯晴”DIY手工团体活动：拼豆活动

| 信息项 | 内容 |
| --- | --- |
| 公告版块 | 工作简报 |
| 发布时间 | 待发布 |
| 发布部门 | 计算机科学与技术学院 |
| 发布范围 | 北京交通大学 |

为丰富同学们的课余生活，锻炼学生动手实践能力，计算机学院学生会实践育人部于2026年3月19日在九教北405开展了第四期“芯晴”DIY手工团体活动。本次活动以拼豆创作为载体，为同学们搭建了交流互动、提升自我的平台，让大家在实践中感受创意的魅力，在协作中收获成长与快乐。

活动现场秩序井然，氛围融洽。工作人员提前做好筹备工作，整齐摆放好彩豆、模板、工具等物料，为活动的顺利开展提供了有力保障。参与活动的同学们准时到场、有序就座，迅速投入到手工创作中。

活动过程中，同学们态度认真、专注投入，有的对照模板细致挑选彩豆，精准完成拼接；有的充分发挥想象力，突破模板限制，设计出独具特色的作品。创作过程中，大家相互交流经验、彼此提供帮助，在协作中增进了友谊，也让实践的意义得到进一步体现，切实践行实践育人部“以实践促成长”的工作宗旨。

本次活动出现了不少优秀作品，每一件作品都凝聚着同学们的耐心与创意。作品风格多样、色彩斑斓，既有充满个性的创意设计，也有简约大气的特色标识，充分展现了同学们的动手能力与创新思维。这些作品不仅是同学们手工技艺的生动展现，更是本次实践活动成果的直接体现，彰显了同学们积极向上、乐于实践的精神风貌。

此次拼豆实践活动作为学生会实践育人部本学期的开篇之作，既丰富了同学们的课余文化生活，缓解了学习压力，也有效锻炼了大家的耐心、专注力与动手实践能力。计算机学院学生会实践育人部也将继续立足工作职能，策划开展更多形式多样、富有意义的实践活动，为同学们提供更多实践锻炼的机会，助力同学们在实践中成长、在实践中进步。
